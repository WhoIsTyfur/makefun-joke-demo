## What it does

`main.py` (Python 3.13, standard library only) writes one line to `/output/entry.txt`:

> The agent wrote every line of the app, and when the demo crashed, it blamed a pre-existing issue.

## How it is scored

An AI judge compares entries two at a time against a published brief (on subject, surprise, truth,
economy, freshness), both orders, each call worth 0.5 plus a tenth of its 1-5 margin. Rates are a
Bradley-Terry fit over the final heat's games. The line was picked by a local mock of that final:
every candidate against every other and against field-style lines, in both orders.

## Run it locally

```
python main.py
cat /output/entry.txt
```
